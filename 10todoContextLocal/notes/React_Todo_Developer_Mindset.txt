Phase 3: Why Context?

Context solves prop drilling.
It doesn't create state—it shares it.

Phase 5: Function design

Add:
Create new todo and:

Delete:
todos.filter(todo => todo.id !== id)

Toggle:
Use map() to replace only the clicked todo.
